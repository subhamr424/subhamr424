## ⚡ Engineering Profile

I'm a **DevOps Engineer with 3+ years of experience** working across cloud infrastructure, containerized workloads, CI/CD, Kubernetes, automation, and production operations.

My focus is simple:

I work across the complete delivery lifecycle — from infrastructure provisioning and containerization to Kubernetes deployments, GitOps, monitoring, troubleshooting, and production reliability.
